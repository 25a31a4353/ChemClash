# ChemClash
ChemClash is an AI-powered, gamified Organic Chemistry platform that turns learning into an e-sport. Featuring live 1v1 mechanism duels, an interactive drag-and-drop mechanism builder, and a real-time Socratic AI tutor that debugs your chemical logic instead of just giving answers. Master reaction pathways through addictive, tactile gameplay.

## Quick start

```bash
# 1. Install backend dependencies (once)
pip install -r backend/requirements.txt

# 2. Install frontend dependencies (once)
cd chemclash && npm install && cd ..

# 3. Copy env file and fill in your API key (once)
cp backend/.env.example backend/.env

# 4. Start everything with one command
python start.py
```

- **Backend API** → http://localhost:8000
- **Frontend**    → http://localhost:3000

Press `Ctrl+C` to stop both servers.
